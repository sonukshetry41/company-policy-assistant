About the Approaches

Rules-Based: Matches question keywords against policy titles and text without using an LLM.

LLM Without Vector Index: Sends the complete policy database to an LLM.

LLM With Vector Index: Uses TF-IDF vectors and cosine similarity to retrieve relevant policies before sending them to an LLM.
